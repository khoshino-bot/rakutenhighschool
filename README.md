# 最強プラン診断士 かんたん見積システム

JOB DRAFT FES 2026 おしごと体験ブース用の料金見積ツール。**`index.html` 1ファイルだけで動きます**（ネット接続不要）。

## 当日の使い方（スタッフ向け）

1. タブレットで `index.html` を開く（ホーム画面に追加しておくと全画面で使えます）
2. 「診断をはじめる」→ 端末 → プラン → オプション → 見積結果 の順に高校生がタップ
3. 次の体験者に交代するときは **「最初から」** をタップ（選択内容はすべて消えます）
4. 画面が固まったと感じたら、ブラウザの再読み込みで最初に戻ります。何も保存されないので何度やっても大丈夫です

## 複数台への配り方

- `index.html`（端末画像を使う場合は `img/` フォルダも）をそのままコピーするだけ。AirDrop・USB・共有ドライブいずれでも可
- 画像を使わない場合は本当に1ファイルだけで動きます

## 金額・名称の変え方（プログラム知識は不要）

`index.html` をテキストエディタで開き、`★★ マスタデータ` と書かれた場所の下にある `MASTER` の中だけを書き換えて保存します。

| 変えたいもの | 場所 |
|---|---|
| プラン名 | `plan.name` の文字列。ここ1か所で全画面に反映 |
| データ段階のラベル・目安・月額 | `plan.tiers` の各行 |
| 割引の名前・条件・金額 | `discounts` |
| オプションの名前・説明・月額 | `options` |
| 端末の機種名・一言・本体価格・画像・ポイント還元 | `devices`（画像は `image: 'img/ファイル名.png'`） |
| 支払回数の初期値 | `defaultPayment` |

- 金額はすべて**税込の整数**で入力します
- `MASTER` より下（`状態` と書かれた行以降）は触らないでください
- 書き換えたら、投入日のコメント（`投入日:`）も更新してください

## 計算ルール

月額合計 ＝ プラン料金 ＋ オプション合計 ＋ 端末の月々支払額（本体価格 ÷ 回数、円未満切り捨て。一括は 0） － 割引合計。0円未満は 0円。
一括払いのときは「初回のお支払い」を、ポイント還元があるときは「別途 ◯◯ポイント還元」を月額とは分けて表示します。
